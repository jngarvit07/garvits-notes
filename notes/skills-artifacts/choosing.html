Choosing between them

2 min read No experience needed
💡
In plain English
Four options, and one question each. Does it need to do something? A tool. Does it need to know something it was not trained on? Retrieval. Does it need to know how you do things? A skill. Does the output need to persist as a document? An artifact. Most confusion here dissolves once you ask which of those four you actually have.
✓ Worth remembering
  • Tools add ability, RAG adds facts, skills add know-how, artifacts add a place to put the result. Different problems.
  • If the facts are right but the procedure is wrong, no amount of retrieval will fix it. That is a skill.
  • A skill’s description is the only part always in context — write it as a trigger in the words people actually use.
  • Progressive disclosure is the point: one line always, the body on demand, references only when needed.
  • Agent Skills go through container on a normal Messages call. That is not Managed Agents.
  • Output with an audience deserves a URL. Output that only lives in a transcript gets lost.
Your assistant keeps formatting reports the wrong way, even though the correct format is written in a document it can retrieve. Which of the four do you need?Answer

A skill, not retrieval. Retrieval puts the format document in front of the model as information, and information competes with everything else in the context. A skill is procedural know-how that loads when the task matches and tells the model how to behave.

The distinction is facts versus method. “What is our refund policy” is retrieval; “how we write a report” is a skill.
