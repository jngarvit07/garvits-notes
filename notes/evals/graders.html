How to score an answer

2 min read Some experience helps
💡
In plain English
Four ways to score an answer, from cheap and rigid to expensive and flexible. Exact match, when there is one right string. A rule or regular expression, when you can describe correctness. A human, which is the ground truth and does not scale. Or another model as judge — which works, provided you have checked the judge against human scores first.

Four kinds of grader, cheapest and most reliable first. Use the simplest one that can actually judge your task — and use several together, because most tasks have both a checkable part and a judgeable part.

Exact / structuralString match, JSON schema validation, a regex.Classification, extraction, routing, anything with one right answer.Nothing — use it wherever it applies. It is free and it never lies.

LLM-as-judgeA model scores the answer against a written rubric.Tone, helpfulness, reasoning quality — the genuinely subjective parts.Biased, and noisier than people expect. See below.

!

Reach for the judge last, not first. “Have a model grade it” feels like the general solution, so it gets used for things a three-line assertion would check exactly. If the requirement is “returns valid JSON with these five fields”, that is JSON.parse and a schema, not a judgement call.

Making an LLM judge trustworthy

Write a real rubric

“Rate helpfulness 1–10” produces noise. Define what each score means, in sentences, with an example of the boundary between adjacent scores.

Prefer binary questions

“Is every factual claim supported by the provided context? Yes or no.” is far more stable than any 1–10 scale, and far easier to act on.

Show the criteria, not the answer key

Given a reference answer, judges drift towards rewarding similarity to it rather than correctness. Different wording is not a failure.

Calibrate against humans

Mark fifty cases by hand and check the judge agrees. If it does not, fix the rubric before trusting a single score it produces.

i

Known judge biases, all measurable: they prefer longer answers, they prefer answers that resemble their own style, and in pairwise comparisons the order you present the two options changes the winner. Randomise the order and check whether the result holds.
