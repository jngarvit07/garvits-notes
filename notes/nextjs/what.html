What Next.js adds to React

2 min read Some experience helps

React draws a screen. It has no opinion about how somebody gets to that screen, where the HTML comes from the first time, or what happens if they have a slow phone. Next.js is the answer to all of that: a framework that wraps React and supplies the parts a real website needs.

💡
In plain English
React is an engine. Next.js is the car built around it — wheels, steering, a chassis and a number plate. You can build your own car around the engine, and for the first month it goes well.
Problem React does not solveWhat Next.js does
How does a URL become a screen?Folders under app/ are the routes. No routing configuration exists.
What does the first response contain?HTML, rendered on the server, so the page appears before any JavaScript loads.
How much JavaScript reaches the browser?Only components you mark as interactive. The rest never ships.
Where does the API live?route.ts files, if you want them in the same project.
Images, fonts, page titles, sitemaps?Built in, and correct by default.
i
This product does not use Next.js for its API. The backend is a separate Express service, and the frontend calls it over HTTP through services/api.ts. That is a deliberate split: the API has to serve published sites and jobs that have nothing to do with this frontend, so it lives on its own.
